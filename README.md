Medical Insurance Cost Analysis
Overview
This project analyzes a medical insurance dataset using Python, Pandas, and Matplotlib.

Dataset Features
Age
Sex
BMI
Children
Smoker Status
Region
Insurance Charges
Analysis Performed
Average age analysis
Average BMI analysis
Average insurance charges
Smoker vs non-smoker comparison
Regional charge comparison
Children vs charges analysis
BMI vs charges analysis
Key Findings
Smokers have significantly higher insurance charges than non-smokers.
Higher BMI is generally associated with higher insurance costs.
Regional differences exist across the United States.
Age and BMI both contribute to insurance costs.
